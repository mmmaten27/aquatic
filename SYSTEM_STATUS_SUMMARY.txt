===== สรุปสถานะระบบตรวจจับและแสดงผล (31 May 2026) =====

=== หลักการทำงานของระบบ (Logic Overview) ===

1. การตรวจจับคนเข้า-ออก (ENTER/EXIT)
   - ใช้กล้อง 4 ตัว:
     - 攝影機1 (YOLO/cam_id=0): กลางห้อง — body detection + face rec (ไกล)
     - 攝影機2 (cam_id=1): จ่อหน้าประตู — face rec หลัก (ENTER trigger)
     - 攝影機3 (cam_id=2): ด้านข้างพื้นที่หน้าประตู — body/face (ปัจจุบัน face rec ไม่ได้ผล)
     - 攝影機4 (cam_id=3): หันเข้าห้องจับหน้าตอนออก — face rec + YOLO proxy fallback
   - Face recognition: ArcFace (InsightFace buffalo_l) + cosine distance
   - CAM_NO_FACE_RECOGNITION = set() (ยกเลิก — ทุกกล้องลองสแกนหน้า)

2. State Machine (unified_state_machine)
   - person_state: {face_folder: {inside, entered_at, entered_at_timestamp, last_seen{cam_id}, last_confidence, exit_pending, ...}}
   - ENTER Logic: เมื่อคนอยู่นอก (inside=False)
       เช็ค last_seen[cam_id] < ENTRY_WINDOW_SEC (12วินาที)
       เงื่อนไข ENTER:
         - cam1_solo: CAM1 (攝影機2) เห็น + confidence >= 0.40
         - cam2_solo: CAM2 (攝影機3) เห็น + confidence >= 0.80 (ใช้ไม่ได้)
         - cross_conf: CAM1 + CAM2 เห็นพร้อมกัน (ใช้ไม่ได้)
       → ใช้ cam1_solo เป็นหลัก + VOTE_REQUIRED=1 (識別ครั้งเดียวจบ)
   - EXIT Logic (2-Stage + Grace Period): เมื่อคนอยู่ในห้อง (inside=True)
       Stage 1: CAM3 (攝影機4) เห็นคนภายใน EXIT_WINDOW_SEC (8วิ) → exit_pending=True
         - CAM3 พยายาม scan หน้าก่อน ถ้าไม่ได้ → YOLO body proxy infer
       Grace Period: ถ้าเพิ่ง ENTER <30วิ → EXIT IGNORED (ป้องกัน EXIT วน)
       Stage 2: รอ EXIT_CONFIRM_DELAY_SEC (8วิ) แล้วตรวจสอบว่ายังมีคนอยู่ไหม
         - เช็ค CAM1 (攝影機2) OR CAM2 (攝影機3) OR YOLO (攝影機1)
         → ถ้ายังมีใครเห็น → EXIT CANCELLED
         → ถ้าไม่เห็นเลย → EXIT CONFIRMED
       Timeout: EXIT_MAX_WAIT_SEC = 30วิ → force EXIT

3. Voting Mechanism
   - VOTE_REQUIRED=1 (識別ครั้งเดียวพอ — face rec มี quality gates แล้ว)
   - CAM2 (攝影機3) update ทันทีไม่ต้อง vote
   - CAM1 + CAM3 ใช้ vote 1/1

4. Dashboard / Frontend
   - /api/room/status → person_state[inside=True] → 在室人員
   - /api/face/latest → latest_face_list (จาก YOLO track_identity) + cam2_face_list
   - /api/occupancy → room_occupants (ENTER/EXIT event-based)

=== ปัญหาที่แก้แล้ว ===

1. "ใน室人員" ไม่แสดงผล
   - สาเหตุ: JavaScript ใช้ ID side-occupants-list/badge/empty
     แต่ HTML ใช้ occupant-list/occupant-count-badge/occupant-empty-badge
   - แก้: เปลี่ยน JS ID ให้ตรงกับ HTML (index.html:1362-1364)

2. Unknown alert (未知人員) ผิด (ครั้งที่ 1)
   - สาเหตุ: _cleanup_stale_tracks() เช็คทีละ Track-ID
     แต่ YOLO สร้างหลาย Track-ID ต่อคนเดียว
     Track 13,15,16,17 ไม่ถูกจำ → alert ทั้งที่ Track 18 จำคนได้
   - แก้: เพิ่ม any_identified flag ก่อน alert (app.py:718)

3. Unknown alert (ครั้งที่ 2)
   - สาเหตุ: Track เก่า timeout ก่อน Track ใหม่識別 → alert ปลอม
   - แก้: YOLO cam ไม่ยิง unknown alert — CAM1 (攝影機2) จัดการแทน
     (app.py:740-747)

4. latest_face_list ค้างคนเก่า
   - สาเหตุ: อัปเดทเฉพาะเมื่อ current_tracks มีค่า
     ไม่มี else ล้าง list
   - แก้: เพิ่ม else: latest_face_list = [] (app.py:872)

5. FACE DB rebuild ซ้ำหลายรอบ
   - สาเหตุ: _ensure_db() ไม่มี lock → หลาย thread rebuild พร้อมกัน
   - แก้: เพิ่ม _db_building + _db_build_lock (face_utils.py:34-36, 130-143)
   - เพิ่ม _build_db() ตอน startup (app.py:2242)

6. EXIT Loop (ENTER → EXIT → ENTER)
   - สาเหตุ: EXIT ตรวจสอบแค่ cam2_still_sees ซึ่งเป็น False เสมอ
   - แก้: เพิ่ม yolo_still_sees ในเงื่อนไข (app.py:1597-1599)
     "no camera sees them → EXIT" / "YOLO still sees → CANCELLED"

7. EXIT ทันทีหลัง ENTER (Round 2)
   - สาเหตุ: cam3 เห็นคนที่ทางออกทันทีที่เดินเข้า → EXIT PENDING ทันที
   - แก้: เพิ่ม Grace Period 30วินาทีหลัง ENTER (EXIT IGNORED)
     + เช็ค cam1_still_sees (攝影機2) เพิ่มใน still_sees
     (app.py:1607-1614)

8. Telegram spam (Round 2)
   - สาเหตุ: ส่ง notification ทุก ENTER
   - แก้: เพิ่ม _do_notify_enter debounce 60วิ/คน (app.py:1428-1438)

9. VOTE_REQUIRED=2 ไม่มีวันถึง (Round 2)
   - สาเหตุ: แต่ละ Track-ID識別แล้ว cached → โหวตแค่ครั้งเดียว
   - แก้: VOTE_REQUIRED=2→1 (app.py:127)
     (face rec มี quality gates เพียงพออยู่แล้ว)

10. Crop ใบหน้าพลาด (Round 2)
    - สาเหตุ: crop top 40% ของ YOLO box → ได้หัวไหล่ ไม่ใช่ใบหน้า
    - แก้: 40%→30%, margin 8%→5% (app.py:695-697)

11. _ensure_db() global variable error (Round 2)
    - สาเหตุ: ขาด global declaration → import จากไฟล์อื่น error
    - แก้: เพิ่ม global _db_building, _db_ready (face_utils.py:131)

12. Unknown alert ปลอมจาก YOLO cam (Round 2)
    - สาเหตุ: YOLO cam (กลางห้อง) เห็นคนไกล → หน้า < min_size
      → timeout 15-25วินาที → alert → ทั้งที่ CAM1識別ได้แล้ว
    - แก้: ปิด YOLO unknown alert ให้ CAM1 (攝影機2) จัดการ
      (app.py:739-740)

=== ปัญหาที่ยังเหลือ ===

1. CAM2 (攝影機3 ด้านข้าง) + CAM3 (攝影機4 จับหน้าออก)
   → scan หน้าไม่ได้ ("no face detected" ตลอด)
   → ใช้ YOLO body proxy fallback แทน
   → สาเหตุ: physical camera position (คนหันหลัง/อยู่ไกล)
2. CAM1 (攝影機2 จ่อประตู) ใช้เวลา ~17วินาทีก่อน識別หน้าได้
   → เพราะต้องรอให้คนเดินใกล้พอ (49x63px)
   → ถ้าคนยืนนิ่งหน้ากล้องนานๆติดขัด
3. FACE DB embedding rebuild ตอน startup
   → เสียเวลา ~4-5วินาที ทุกครั้งที่ restart
