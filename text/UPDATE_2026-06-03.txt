ก) สภาพห้องและตำแหน่งกล้อง (Room Layout)
================================================================================

ขนาดห้อง: 6m × 5m
ประตู: บานเดียว ใช้ทั้งเข้าและออก (มุมซ้ายบน)

กล้องทั้ง 4 ตัว:
┌─────────────┬──────────────────────┬─────────────────────────────────────────┐
│ UI          │ ตำแหน่ง              │ หน้าที่ / field of view                  │
├─────────────┼──────────────────────┼─────────────────────────────────────────┤
│ 攝影機 1    │ ผนังขวา (กลาง)       │ YOLO overview, face ระยะไกล             │
│ (YOLO)      │ หันซ้ายเข้าห้อง      │ โต๊ะทำงานอยู่ใต้กล้องนี้ = blind spot  │
├─────────────┼──────────────────────┼─────────────────────────────────────────┤
│ 攝影機 2    │ ผนังซ้าย ใกล้ประตู   │ trigger ENTER, face rec ประตูเข้า       │
│ (cam1)      │ หันขวาเข้าห้อง       │ เห็นหน้าคนตอนเข้า, เห็นหลังคนตอนออก   │
├─────────────┼──────────────────────┼─────────────────────────────────────────┤
│ 攝影機 3    │ มุมขวาบน             │ ยืนยัน presence ภายในห้อง              │
│ (cam2)      │ หันซ้าย-ล่างเข้าห้อง │ เห็นหน้า/ข้างคนเดินในห้อง              │
├─────────────┼──────────────────────┼─────────────────────────────────────────┤
│ 攝影機 4    │ บนผนัง ใกล้ประตู     │ trigger EXIT, เห็นหน้าคนตอนเดินออก    │
│ (cam3)      │ หันเข้าห้อง          │ field of view ครอบคลุมโต๊ะทำงานด้วย   │
└─────────────┴──────────────────────┴─────────────────────────────────────────┘

เส้นทางออก: โต๊ะ → ลุกขึ้น (攝影機 1 อาจเห็น) → เดิน → 攝影機 3 เห็นหลัง
             → 攝影機 4 เห็นหน้า → ออกประตู

Blind spot: โต๊ะทำงานอยู่ใต้ 攝影機 1 → นั่งทำงานแล้วกล้องไม่เห็น
            → ระบบอาจ EXIT ผิดถ้า 攝影機 4 เห็นและกล้องอื่นไม่เห็น
