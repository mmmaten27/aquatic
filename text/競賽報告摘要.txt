================================================================================
  智慧實驗室人員管制與水耕養殖監控系統
  專題報告競賽 — 摘要・目的・成果・結論
================================================================================


================================================================================
一、摘要 (Abstract)
================================================================================

本專題開發一套整合式智慧實驗室管理系統，結合 AI 影像辨識與 IoT 感測器監控
兩大核心功能，部署於實驗室場域中實際運作。

系統以 Python Flask 為核心架構，透過 4 支 USB 監控攝影機，利用 YOLOv8 進行
人體偵測、InsightFace（ArcFace）進行人臉辨識，自動記錄人員進出並即時顯示於
網頁儀表板。同時透過 IoT Sensor Node 蒐集水耕養殖池的水質數據（pH、溶氧量、
溫度、氨氮、濁度、電導率），於網頁上即時呈現並在異常時透過 Telegram 發出通知。

整個系統無需刷卡或手動登錄，完全自動化執行人員管制與環境監控兩項任務。


================================================================================
二、研究目的 (Objectives)
================================================================================

1. 解決傳統人員管制的盲點
   傳統門禁依賴識別卡或簽到本，容易發生代刷、遺忘登記或資料偽造等問題。
   本系統透過人臉辨識取代人工作業，達成「無接觸、自動化、可稽核」的管制目標。

2. 整合異質系統於單一平台
   實驗室同時管理人員安全與養殖環境，過去需分別操作多套獨立系統。
   本專題將人員管制與水耕監控整合於同一網頁儀表板，降低管理複雜度。

3. 建立即時異常預警機制
   無論是陌生人闖入、成員於非授權時段進入，或水質超出安全範圍，
   系統均能在事件發生當下透過 Telegram 傳送通知，縮短反應時間。

4. 驗證低成本 AI 攝影機系統的可行性
   以 USB 監控攝影機搭配開源 AI 模型（YOLOv8 + ArcFace），
   探討在一般硬體環境下能否達到實用等級的辨識準確度與穩定性。


================================================================================
三、研究成果 (Results)
================================================================================

─── 3.1 人臉辨識準確度 ────────────────────────────────────────────────────────

以 3 位成員（Tongen、jiabao、TT）進行測試：

  訓練方式改善前（使用手機拍攝照片）：
  → jiabao、TT 辨識信心值 0.42–0.51，低於門檻值，系統常誤認或無法辨識

  訓練方式改善後（使用監控攝影機現場拍攝，涵蓋 5 種角度）：
  → Tongen：0.63–0.77　jiabao：0.68　TT：0.79
  → 每位成員均可被正確識別

  辨識速度（攝影機 2）：每次約 0.18–0.38 秒

─── 3.2 進出記錄穩定性 ────────────────────────────────────────────────────────

  改善前：系統每隔 1–2 分鐘誤觸 EXIT，在室人員名單持續錯誤
  改善後：Tongen 在室連續 15 分鐘以上，無任何假性 EXIT 發生

─── 3.3 陌生人偵測 ────────────────────────────────────────────────────────────

  在「成員與陌生人同時入鏡」的情境下，攝影機 2 能正確拒絕辨識陌生人
  並即時發送含截圖的 Telegram UNKNOWN 警報，安全缺口已修復。

─── 3.4 水耕養殖監控 ──────────────────────────────────────────────────────────

  ✅ 3 座養殖池、6 項水質指標即時顯示於儀表板
  ✅ 異常持續 30 分鐘 / 2 小時自動升級警報等級
  ✅ 感測器斷線（持續回傳 0）自動偵測並通知
  ✅ 水質恢復正常後自動發送「已恢復正常」通知

─── 3.5 系統整體功能清單 ──────────────────────────────────────────────────────

  ✅ 4 攝影機即時影像串流 + 人臉辨識
  ✅ 自動 ENTER/EXIT 記錄，無需任何人工操作
  ✅ 在室人員狀態即時顯示（姓名 + 已在室時間）
  ✅ 歷史紀錄查詢（依姓名 / 日期篩選，附截圖）
  ✅ Telegram 警報：陌生人、非授權時段、人員出室
  ✅ 人員管理頁面：新增/編輯/刪除成員，5 角度導引拍照
  ✅ 登入認證保護所有頁面（Werkzeug 密碼雜湊）

四、結論 (Conclusions)
================================================================================

1. 技術可行性已驗證
   在一般實驗室環境（普通室內光線、USB 攝影機）下，ArcFace 人臉辨識
   能達到 0.63–0.79 的信心值，足以支撐實際場域的人員管制需求，
   證明低成本硬體搭配開源 AI 模型具備實用價值。

2. 訓練資料品質優於數量
   本專題的關鍵教訓之一：以「與部署環境相同的攝影機」拍攝訓練照片，
   辨識信心值顯著高於使用手機拍攝的照片。
   這說明資料的領域一致性（Domain Consistency）比資料量更為關鍵。

3. 系統整合帶來管理效益
   將人員管制與水耕監控整合於單一儀表板，使管理者能以一個介面
   同時掌握實驗室的人員狀況與養殖池水質，減少切換操作的負擔。

4. 已知限制與未來改善方向

   目前限制：
   ⚠ 多支 USB 攝影機共用同一 USB 匯流排，頻寬不足偶發斷線
   ⚠ 桌面形成攝影機盲區，成員坐定後狀態偶有延遲更新
   ⚠ 低光源環境下辨識信心值下降

   未來方向：
   → 導入 PoE 網路攝影機，解決 USB 頻寬限制
   → 增加攝影機數量或調整安裝角度，消除盲區
   → 嘗試在 Edge 設備（Raspberry Pi / Jetson）上部署，降低對主機依賴
   → 擴充人員資料庫，測試更多人同時在室的辨識穩定性

五、系統架構摘要
================================================================================

  技術堆疊：
  ┌──────────────────────────────────────────────────────────┐
  │  前端        Flask Jinja2 + JavaScript (polling 5s)      │
  │  後端        Python Flask + Waitress (32 threads)        │
  │  AI 偵測     YOLOv8n（人體）+ InsightFace ArcFace（人臉）│
  │  資料庫      MySQL（事件紀錄 + 感測器數據）               │
  │  影像        OpenCV（4 攝影機，各自獨立 Thread，5 fps）   │
  │  通知        Telegram Bot API                            │
  │  驗證        Session + Werkzeug password hash           │
  └──────────────────────────────────────────────────────────┘
