================================================================================
ทำความเข้าใจ — ระบบกราฟทำงานยังไง
================================================================================

ระบบมีกราฟ 2 ระดับ:

  ระดับที่ 1 — Dashboard หลัก (/)
  แสดงค่าปัจจุบันของทุกบ่อในหน้าเดียว
  Frontend ดึงข้อมูลจาก API ทุก 5 วินาที → ตัวเลขอัพเดทอัตโนมัติ
  มีสีบ่งบอกสถานะ: ปกติ / ใกล้เกณฑ์ / เกินเกณฑ์

  ระดับที่ 2 — หน้ารายบ่อ (/tank/1, /tank/2, /tank/3)
  แสดงกราฟเส้น (Line Chart) ของค่าเซ็นเซอร์ย้อนหลัง
  เลือกดูได้ 3 ช่วง: 1 ชั่วโมง / 6 ชั่วโมง / 24 ชั่วโมง
  แต่ละบ่อแสดงกราฟแยกสำหรับ pH, อุณหภูมิ, DO

เทคโนโลยีที่ใช้:
  - Chart.js  → วาดกราฟในเบราว์เซอร์ (frontend)
  - Flask API → ดึงข้อมูลจาก MySQL ตามช่วงเวลาที่เลือก
  - MySQL     → เก็บข้อมูล Time-Series ในตาราง tank1/tank2/tank3

================================================================================
กระบวนการวาดกราฟ (How the Chart is Drawn)
================================================================================

ขั้นตอนตั้งแต่เซ็นเซอร์จนถึงกราฟบนหน้าจอ:

  ① เซ็นเซอร์ส่งข้อมูลเข้า MySQL
     Arduino อ่านค่า pH / อุณหภูมิ / DO แล้วเขียนลงตาราง tank1/tank2/tank3
     แต่ละแถว = ค่าเซ็นเซอร์ ณ เวลาหนึ่ง (Time-Series)

  ② ผู้ใช้เลือกช่วงเวลาบนหน้าเว็บ (1h / 6h / 24h)
     เบราว์เซอร์ส่ง HTTP Request ไปยัง Flask API
     เช่น: GET /api/tank/1/history?hours=6

  ③ Flask ดึงข้อมูลจาก MySQL
     Query เลือกเฉพาะแถวที่ Timestamp อยู่ในช่วงที่ขอ
     ส่งกลับเป็น JSON:
     [
       {"timestamp": "09:00", "pH": 7.1, "temperature": 25.8, "DO": 6.5},
       {"timestamp": "09:05", "pH": 7.2, "temperature": 25.7, "DO": 6.6},
       ...
     ]

  ④ Chart.js รับ JSON แล้ววาดกราฟ
     - แกน X = เวลา (timestamp)
     - แกน Y = ค่าเซ็นเซอร์
     - วาดเป็นเส้น (Line Chart) เชื่อมแต่ละจุดข้อมูล
     - มีเส้น threshold แนวนอน (ขอบเขตค่าปกติ) ประกอบ

  ⑤ กราฟแสดงบนเบราว์เซอร์ทันที
     ไม่ต้อง reload หน้า (JavaScript อัพเดท Chart object โดยตรง)
     ถ้าเปลี่ยนช่วงเวลา → วนซ้ำจากขั้น ② ใหม่

  สรุป Data Flow:
  MySQL → Flask API (JSON) → JavaScript (Chart.js) → กราฟบนหน้าจอ

--------------------------------------------------------------------------------
หัวข้อสไลด์: 感測器數據視覺化
--------------------------------------------------------------------------------

【จุดนำเสนอหลัก】

1. Real-time Dashboard
   - แสดงค่าเซ็นเซอร์ล่าสุดของทั้ง 3 บ่อพร้อมกัน
   - อัพเดทอัตโนมัติทุก 5 วินาที ไม่ต้องรีเฟรชหน้า
   - การ์ดเปลี่ยนสีตามสถานะ:
       สีปกติ  → ค่าอยู่ในเกณฑ์
       สีเหลือง → ค่าใกล้เกณฑ์ (ภายใน 15%)
       สีแดง   → ค่าเกินเกณฑ์

2. Historical Trend Chart (กราฟแนวโน้มย้อนหลัง)
   - กราฟเส้นแสดงการเปลี่ยนแปลงของ pH / อุณหภูมิ / DO
   - เลือกช่วงเวลาได้: 1 ชม. / 6 ชม. / 24 ชม.
   - มีแนวเส้น threshold แสดงขอบเขตที่ยอมรับได้

3. แยกดูรายบ่อ
   - บ่อที่ 1, 2, 3 มีหน้าแสดงผลแยกกัน
   - เปรียบเทียบแนวโน้มแต่ละบ่อได้อิสระ

--------------------------------------------------------------------------------
เนื้อหาตัวอักษรสำหรับใส่สไลด์ (ภาษาจีน)
--------------------------------------------------------------------------------

標題: 感測器數據視覺化

• 儀表板即時顯示3個養殖池的pH值、水溫與溶氧量
• 每5秒自動更新，無需手動刷新頁面
• 數值卡片依狀態變色（正常／警告／超標）
• 歷史趨勢圖可選擇查看過去1小時、6小時或24小時的數據
• 各養殖池設有獨立的詳細頁面，方便個別分析

--------------------------------------------------------------------------------
รูปที่แนะนำประกอบสไลด์
--------------------------------------------------------------------------------

  รูปที่ 1 — Dashboard หลัก
  แสดงการ์ดค่าเซ็นเซอร์ทั้ง 3 บ่อพร้อมกัน
  จุดเด่น: เห็นภาพรวมในหน้าเดียว

  รูปที่ 2 — กราฟเส้นย้อนหลัง (หน้า /tank/X)
  แสดงกราฟ pH หรือ DO ช่วง 1 หรือ 6 ชั่วโมง
  จุดเด่น: เห็นแนวโน้มและจุดที่ค่าผิดปกติ

  รูปที่ 3 (optional) — การ์ดสีแดง/เหลือง
  แสดงตอนค่าเกินเกณฑ์ เพื่อโชว์ระบบ alert สีทำงาน
