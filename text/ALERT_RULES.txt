================================================================================
  หลักเกณฑ์การแจ้งเตือนของระบบ (Alert Rules) — ทุกช่องทาง
================================================================================
อัปเดต: June 2026
ไฟล์นี้สรุปว่า Telegram จะส่งเมื่อไหร่ ไม่ส่งเมื่อไหร่
เพื่อให้ผู้ใช้เข้าใจ pattern และไม่โดนรบกวนเกินจำเป็น

ระบบมี 2 ส่วนที่ส่ง Telegram:
  ก) ระบบตรวจจับบุคคล (Face Detection Access Control)
  ข) ระบบตรวจสอบค่าเซนเซอร์ (Sensor Monitoring)

================================================================================
ก) ระบบตรวจจับบุคคล
================================================================================

--- 1. ENTER (คนรู้จักเข้ามาในห้อง) ---
┌──────────────────────┬──────────┬────────────────────────────────────┐
│ สถานการณ์            │ ส่งTelegram? │ ข้อความ                        │
├──────────────────────┼──────────┼────────────────────────────────────┤
│ authorized + ในเวลางาน│ ❌ ไม่ส่ง  │ (ดู Dashboard แทน)             │
│ authorized + นอกเวลา │ ✅ ส่ง   │ ⚠️ {name} 進入實驗室 (非上班時間)   │
│ unauthorized         │ ✅ ส่ง   │ 🚨 {name} 進入實驗室 (未授權進入)   │
└──────────────────────┴──────────┴────────────────────────────────────┘
Cooldown: ENTER_NOTIFY_COOLDOWN = 60 วินาที ต่อคน
          (ป้องกันซ้ำถ้า state machine สั่ง ENTER ซ้ำ)

* ความต่างระหว่าง "unauthorized" กับ "unknown person":
  - unauthorized  = ระบบจำหน้าได้ รู้ว่าเป็นใคร แต่ไม่มีสิทธิ์เข้า
                    (เช่น เข้าผิดเวลา หรือถูก deactivate ใน Personnel)
  - unknown person = ระบบจำหน้าไม่ได้เลย ไม่มีชื่อในฐานข้อมูล
                    (น่าเป็นห่วงกว่า จึงแนบรูปภาพไปด้วย)

--- 2. EXIT (คนรู้จักออกจากห้อง) ---
┌──────────────────────┬──────────┬────────────────────────────────────┐
│ สถานการณ์            │ ส่งTelegram? │ ข้อความ                        │
├──────────────────────┼──────────┼────────────────────────────────────┤
│ ทุกกรณี               │ ✅ ส่ง   │ 🚶 {name} 離開實驗室 ⏱ X 分鐘   │
└──────────────────────┴──────────┴────────────────────────────────────┘
ส่งทุกครั้ง (closure) ไม่มี cooldown

--- 3. Unknown Person (คนที่ไม่รู้จัก / จำใบหน้าไม่ได้) ---
┌──────────────────────────────┬──────────┬───────────────────────────┐
│ สถานการณ์                    │ ส่งTelegram? │ ข้อความ               │
├──────────────────────────────┼──────────┼───────────────────────────┤
│ เห็นคนแต่จำไม่ได้ครั้งแรก     │ ✅ รอ 15 วิ │ ⚠️ 發現不明人士! + รูป │
│ คนเดิมยังอยู่ ＞ 5 นาที      │ ✅ ซ้ำ    │ ⚠️ 發現不明人士! + รูป │
│ unknown person ออกจากห้อง    │ ✅ ส่ง    │ ✅ 不明人士已離開           │
└──────────────────────────────┴──────────┴───────────────────────────┘
Cooldown: UNKNOWN_COOLDOWN_SEC = 300 วินาที (5 นาที) ต่อกล้อง
เฉพาะ CAM1 (กล้องหน้าประตู) ที่ส่ง unknown alert

================================================================================
ข) ระบบตรวจสอบค่าเซนเซอร์
================================================================================

--- 4. Sustained Alert (ค่าเกินเกณฑ์ติดต่อกันนาน) ---
ค่าที่ตรวจ: pH (6.5-7.5), อุณหภูมิ (22-27°C), DO (6.0-8.0 mg/L)

┌──────────────────────────────────────┬──────────┬────────────────────┐
│ สถานการณ์                            │ ส่งTelegram? │ ข้อความ        │
├──────────────────────────────────────┼──────────┼────────────────────┤
│ ค่าเกินเกณฑ์ทันที (< 30 นาที)        │ ❌ ไม่ส่ง  │ (UI แดงอย่างเดียว) │
│ ค่าเกินเกณฑ์ ≥ 30 นาที ติดต่อกัน     │ 🟡 ครั้งที่ 1 │ แจ้งค่า        │
│ ค่าเกินเกณฑ์ ≥ 2 ชม. หลังครั้งแรก   │ 🔴 ครั้งที่ 2 │ แจ้งซ้ำ        │
│ ค่ากลับมาปกติ (หลังจากเคยแจ้ง)       │ ✅ recovery │ แจ้งปกติแล้ว    │
└──────────────────────────────────────┴──────────┴────────────────────┘

จำนวนสูงสุดต่อ sensor ต่อ 1 รอบ: 2 Telegram + 1 recovery
logic: นับเวลาต่อเนื่องนับตั้งแต่วินาทีที่ค่าเริ่มเกิน ถ้าค่ากลับมาในเกณฑ์
       แล้วเกินอีก → เริ่มนับเวลาใหม่ (รอบใหม่)

--- 5. Approaching Warning (ใกล้จะถึงเกณฑ์ แต่ยังไม่เกิน) ---
┌──────────────────────────────────────┬──────────┬────────────────────┐
│ สถานการณ์                            │ ส่งTelegram? │ UI              │
├──────────────────────────────────────┼──────────┼────────────────────┤
│ ค่าอยู่ใน range แต่ห่างขอบ ≤ 15%     │ ❌ ไม่ส่ง  │ 🟠 การ์ดสีส้ม      │
│ ค่าอยู่ใน range ห่างขอบ > 15%        │ ❌ ไม่ส่ง  │ ✅ สีปกติ          │
└──────────────────────────────────────┴──────────┴────────────────────┘
Visual-only, ไม่มี Telegram

--- 6. Sensor Fault (เซนเซอร์เสีย/หลุด) ---
┌──────────────────────────────────────┬──────────┬────────────────────┐
│ สถานการณ์                            │ ส่งTelegram? │ ข้อความ        │
├──────────────────────────────────────┼──────────┼────────────────────┤
│ ค่าเป็น 0 ≥ 2 นาที ติดต่อกัน         │ 🔌 ส่ง    │ 🔌 感測器異常!    │
│ ค่ากลับมาไม่ใช่ 0 หลังจากเคย fault   │ ✅ recovery│ ✅ 感測器恢復正常  │
└──────────────────────────────────────┴──────────┴────────────────────┘
Cooldown: 60 นาที (กันส่งซ้ำถ้าเป็น 0ๆ咳嗽咳嗽咳嗽く)
threshold: 24 ครั้งติดกัน (~2 นาทีที่ interval 5 วินาที)

================================================================================
ค) ตารางรวม Telegram ทั้งหมดที่ผู้ใช้จะได้รับ
================================================================================

เหตุการณ์ปกติในเวลางาน (เช้า 08:00-17:00):
  - ไม่มี Telegram ใดๆ (คนเข้าออกปกติ, sensor อยู่ในเกณฑ์)

เหตุการณ์ที่ได้รับ Telegram (รวมทุกส่วน):
  ─ 🟡/🔴 ค่า sensor เกินเกณฑ์ ≥ 30 นาที / 2 ชั่วโมง
  ─ 🔌 Sensor อ่านค่า 0 ≥ 2 นาที
  ─ ✅ Recovery เมื่อค่ากลับมาปกติ
  ─ ⚠️/{name} ENTER นอกเวลางาน
  ─ 🚨 ENTER unauthorized
  ─ 🚶 EXIT (ทุกกรณี)
  ─ ⚠️ Unknown person เข้ามา
  ─ ✅ Unknown person ออกไป

================================================================================
ง) การตั้งค่าที่แก้ไขได้
================================================================================

ไฟล์ detection/config.py:
  ACTIVE_START = "08:00"    # เวลาเริ่มงาน
  ACTIVE_END   = "17:00"    # เวลาเลิกงาน

ค่าใน index.html (frontend):
  SENSOR_ALERT_CONFIG.ph   = { alert1Min: 30, alert2Min: 120 }  # นาที
  SENSOR_ALERT_CONFIG.temp = { alert1Min: 30, alert2Min: 120 }
  SENSOR_ALERT_CONFIG.do   = { alert1Min: 30, alert2Min: 120 }
  ZERO_FAULT_THRESHOLD     = 24  # จำนวนครั้ง (~2 นาที)

ค่าใน app.py (backend):
  UNKNOWN_COOLDOWN_SEC     = 300    # 5 นาที
  UNKNOWN_DEFER_SEC        = 15     # รอก่อนแจ้ง unknown ครั้งแรก
  ENTER_NOTIFY_COOLDOWN    = 60     # 60 วิ ต่อคน

================================================================================
จ) Flow การตัดสินใจของ Sensor Alert
================================================================================

fetchTankData(tankId)  ← ทุก 5 วินาที
  │
  ├── ขั้น 1: Stale? (ข้อมูล > 15 วิ)
  │       └── แสดง "離線" ทุกการ์ด
  │
  ├── ขั้น 2: checkSensorFault()
  │       ├── value === 0 → zeroCount++ → ≥ 24? → 🔌 ส่ง Telegram
  │       └── value !== 0 → zeroCount=0 → ถ้าเคย fault → ✅ recovery Telegram
  │
  ├── ขั้น 3 (ถ้าไม่ fault): checkAlert()
  │       ├── value เกินเกณฑ์ → เริ่มนับเวลา sustainedAlert
  │       ├── ≥ 30 นาที → 🟡 ส่ง Telegram ครั้งที่ 1
  │       ├── ≥ 2 ชม.   → 🔴 ส่ง Telegram ครั้งที่ 2
  │       └── value กลับมาในเกณฑ์ → ✅ recovery Telegram (ถ้าเคยแจ้ง)
  │
  └── ขั้น 4 (ถ้าไม่ fault): analyzeApproach()
          └── visual-only amber เมื่อค่าใกล้ขอบเขต 15%
