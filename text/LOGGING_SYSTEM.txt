================================================================================
  ระบบ Logging — คำอธิบาย
================================================================================
ไฟล์นี้สรุปวิธีการทำงานของระบบ logging ใหม่ หลังจากปรับลด noise บน terminal

================================================================================
1. หลักการ
================================================================================
Log แบ่งเป็น 2 ระดับ:

  iprint() — IMPORTANT: แสดงบน terminal + บันทึกไฟล์
             ใช้กับ: ✅ ตรวจจับเจอคน, 🚪 ENTER/EXIT, ⚠️ error, 🗳️ vote ผ่าน

  dprint() — DETAIL:  บันทึกไฟล์อย่างเดียว (ไม่แสดง terminal)
             ใช้กับ: 🔬 face rec details, 🏠 state machine, 📐 size penalty
             ถ้า VERBOSE=True → ก็แสดง terminal ด้วย

================================================================================
2. ไฟล์ log ละเอียด
================================================================================
  ตำแหน่ง: detection/detailed_log.txt

  ไฟล์นี้บันทึกทุกบรรทัด ทั้ง iprint และ dprint (ไม่มีการตกหล่น)
  ใช้ timestamp ด้วย

  ตัวอย่างเนื้อหาในไฟล์:
    14:30:01 🔍 CAM1: detected 1 person(s), max_conf=0.85
    14:30:01 📸 CAM1: frame source=best(0.723), buffer_size=5
    14:30:01 🔬 FACE[cam1]: best=0.31(Std001) 2nd=0.87(std2) | db=10 embs | thresh=0.55 | took=0.045s
    14:30:01 ✅ TRACK 3: identified as สมชาย (authorized) conf=0.69
    14:30:02 🏠 STATE Std001: inside=False cam1=True(0.85) cam2=False(0.00) cam3=False → cam1_solo=True

  วิธีดู log แบบ real-time (Windows PowerShell):
    Get-Content detection/detailed_log.txt -Wait

================================================================================
3. การเปิด/ปิด verbose
================================================================================
  แก้ไขไฟล์ detection/log_utils.py บรรทัดที่ 16:

    VERBOSE = False   ← ปกติ: ไม่แสดง dprint บน terminal
    VERBOSE = True    ← debug: แสดงทุกอย่างบน terminal (เหมือนเดิม)

================================================================================
4. สรุป terminal output ที่เปลี่ยนไป
================================================================================

  สถานการณ์ idle (ไม่มีคน):

    ก่อน:                      หลัง:
    ─────────────────────────  ─────────────────────────
    🔬 FACE[cam0]: best=...   (ไม่มี output)
    🏠 STATE Std001: ...      (ไม่มี output)
    🗳️ CAM1 vote: ...        (ไม่มี output)
    📐 FACE: small face...    (ไม่มี output)
    ❌ error, CRASH            ❌ error, CRASH (ยัง)
    🔍 CAM1: detected 0...    (ไม่มี output)
    🗑️ CLEANUP: removed 0...  (ไม่มี output)
    🔄 ACCESS RULES: refresh   (ไม่มี output)
    ──────────── 120+ บรรทัด/นาที ──── 0-2 บรรทัด/นาที ───

  สถานการณ์มีคน:

    terminal จะเห็นเฉพาะ:
      ✅ TRACK *: identified as ...
      🚪 ENTER logged: ...
      🚶 EXIT logged: ...
      🗳️ VOTE THRESHOLD REACHED
      🔍 CAM*: detected N person(s) (ถ้า N>0)
      ⚠️ UNKNOWN: cam* alert sent
      ❌ errors, crashes

================================================================================
5. แนวทางการใช้
================================================================================
  ─ ปกติรันระบบ:   VERBOSE = False → terminal สะอาด
  ─ debug:          VERBOSE = True  → terminal แสดงทุกอย่าง (เหมือนก่อนเปลี่ยน)
  ─ เช็ค log ย้อนหลัง: เปิด detailed_log.txt
  ─ ดู log สด:        Get-Content detection/detailed_log.txt -Wait
