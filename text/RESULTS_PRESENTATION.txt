0. สิ่งที่ระบบทำได้ (System Capabilities)
================================================================================

ระบบนี้ทำงานได้ 2 ด้านหลักพร้อมกัน:

─── ด้าน 人員管制 (Access Control) ─────────────────────────────

  ✅ จดจำสมาชิกแบบ Real-time จากกล้อง 4 ตัวพร้อมกัน
     ระบบรู้ว่า "คนนี้เป็นใคร" ด้วยการวิเคราะห์ใบหน้าโดยอัตโนมัติ

  ✅ บันทึกการเข้าออกห้องโดยไม่ต้องแตะบัตรหรือกดปุ่ม
     ทุกครั้งที่มีคนผ่านประตู ระบบบันทึกชื่อ เวลา และระยะเวลาที่อยู่

  ✅ แสดงสถานะห้องแบบ Real-time บน Dashboard
     เห็นได้ทันทีว่าตอนนี้มีใครอยู่ในห้องบ้าง

  ✅ ดูประวัติการเข้าออกย้อนหลัง
     ค้นหาตามชื่อหรือวันที่ได้ พร้อมรูปภาพประกอบ

  ✅ แจ้งเตือน Telegram เมื่อเกิดเหตุการณ์ผิดปกติ
     - พบคนแปลกหน้า → ส่งรูปพร้อมแจ้งเตือนทันที
     - สมาชิกเข้าห้องนอกเวลา → แจ้งเตือน
     - สมาชิกออกจากห้อง → แจ้งพร้อมระยะเวลาที่อยู่

─── ด้าน Aquaponics Monitoring ─────────────────────────────────

  ✅ แสดงค่าเซ็นเซอร์ 3 บ่อแบบ Real-time
     pH, อุณหภูมิ, DO (ออกซิเจนละลายน้ำ)

  ✅ แจ้งเตือนเมื่อค่าผิดปกติ (30 นาที / 2 ชั่วโมง)
     ระบบนับเวลาต่อเนื่อง ถ้าเกินเกณฑ์นานพอ → Telegram

  ✅ ตรวจจับเซ็นเซอร์ขัดข้อง
     ถ้าส่งค่า 0 ต่อเนื่อง → แจ้งเตือนว่าอาจเสียหรือหลุด

  ✅ ดูกราฟประวัติค่าเซ็นเซอร์ย้อนหลัง
     เลือกดูได้ 1 / 6 / 24 ชั่วโมง

  ┌──────────┬──────────────────────────┬──────────────────────────┐
  │ สมาชิก  │ ก่อนถ่ายรูปใหม่          │ หลังถ่ายรูปใหม่          │

  攝影機 2: ~0.18-0.38 วินาที/ครั้ง

  เมื่อคนนอกเข้ามาพร้อมสมาชิก (Multi-person scenario)

2. ภาพ Demo (Screenshots)
================================================================================

  รูปที่ 1 — Dashboard หลัก
  แสดง: Live camera 4 ตัว + 在室人員 + ค่าเซ็นเซอร์บ่อปลา
  จุดเด่น: ระบบ 2 อย่างรวมอยู่หน้าเดียว

  รูปที่ 2 — การจดจำใบหน้า Real-time
  แสดง: Bounding box สีเขียว + label "Authorized: Tongen"
  จุดเด่น: ระบบรู้ว่าเป็นใครทันทีที่เห็นหน้า

  รูปที่ 3 — 在室人員 (คนในห้องตอนนี้)
  แสดง: ชื่อสมาชิก + เวลาที่เข้า + ระยะเวลาที่อยู่
  จุดเด่น: อัพเดทอัตโนมัติโดยไม่ต้องมีคนกด

  รูปที่ 4 — 出入紀錄 (ประวัติการเข้าออก)
  แสดง: รายการ ENTER/EXIT พร้อมเวลาและระยะเวลาอยู่
  จุดเด่น: บันทึกครบโดยไม่ต้องใช้บัตรหรือลายเซ็น

  รูปที่ 5 — Telegram Notification
  แสดง: ข้อความแจ้งเตือนจริงบน Telegram
  (⚠️ UNKNOWN / 🚨 ไม่ได้รับอนุญาต / 🚶 ออกจากห้อง)

  รูปที่ 6 — Log ระบบ (system_events.log)
  แสดง: บันทึก ENTER/EXIT/Face Recognition พร้อม timestamp
  จุดเด่น: แสดงให้เห็นว่าระบบทำงานจริง

3. เปรียบเทียบก่อน/หลังพัฒนา (Before / After)
================================================================================

─── ปัญหา 1: รูปฝึกจากโทรศัพท์ ───────────────────────────────

  ก่อน:
  - รูปถ่ายจากโทรศัพท์ มุมและแสงไม่ตรงกับกล้อง surveillance
  - jiabao และ TT ได้ confidence 0.42-0.51 (ต่ำกว่า threshold)
  - ระบบจำ jiabao และ TT เป็น Tongen แทน

  หลัง:
  - ถ่ายรูปจากกล้อง surveillance จริง ครบ 5 ท่า
  - confidence ขึ้นเป็น 0.68-0.79
  - แต่ละคนถูกระบุตัวตนได้ถูกต้อง

─── ปัญหา 2: False EXIT ────────────────────────────────────────

  ก่อน:
  - EXIT ผิดพลาดทุก 1-2 นาที
  - State วนซ้ำ ENTER/EXIT ไม่หยุด
  - 在室人員 แสดงผลไม่ตรงความจริง

  หลัง:
  - Tongen อยู่ในห้อง 15+ นาทีโดยไม่มี false EXIT
  - 在室人員 แสดงผลถูกต้อง
  - บันทึกประวัติสมเหตุสมผล

─── ปัญหา 3: UNKNOWN ไม่ขึ้นเมื่อคนนอกเข้ามาพร้อมสมาชิก ───────

  ก่อน:
  - คนนอกถูกจำเป็น Tongen
  - ไม่มี UNKNOWN alert เลย
  - security gap ที่อันตราย

  หลัง:
  - 攝影機 2 ปฏิเสธการจำ → ส่ง UNKNOWN alert ✅
  - แก้ logic ให้ตรวจ UNKNOWN แยกอิสระ
    (ไม่ขึ้นกับว่ามีสมาชิกอยู่ในเฟรมเดียวกันหรือไม่)
