================================================================================
  方法 (Method) — วิธีการทำงานของระบบ
  IoT Lab Monitoring & Access Control System
================================================================================

ระบบนี้แบ่งออกเป็น 6 ส่วนหลัก ทำงานร่วมกันแบบ Real-time

================================================================================
ส่วนที่ 1 — สถาปัตยกรรมระบบ (System Architecture)
================================================================================

ระบบพัฒนาบน Python Flask เป็น Web Application ที่รวม 2 ระบบหลักไว้ด้วยกัน:

  [กล้อง 4 ตัว] ──→ [AI Detection] ──→ [Access Control]
                                               ↓
  [Sensor IoT]  ──→ [Database MySQL] ──→ [Web Dashboard]
                                               ↓
                                     [Telegram Notification]

เทคโนโลยีหลักที่ใช้:
  - Python Flask     : Web framework + REST API
  - YOLOv8n          : Person detection (body)
  - InsightFace ArcFace : Face recognition (identity)
  - MySQL            : ฐานข้อมูล
  - OpenCV           : Video capture + image processing
  - Telegram Bot API : การแจ้งเตือน
  - Waitress         : Production server (32 threads)

================================================================================
ส่วนที่ 2 — ระบบกล้องและการตรวจจับบุคคล (Camera & Person Detection)
================================================================================

ใช้กล้อง USB 4 ตัว แต่ละตัวมีหน้าที่ต่างกัน:

  攝影機 1 (YOLO Overview)
  → ติดผนังด้านขวา หันเข้าห้อง
  → ทำหน้าที่: ตรวจจับร่างกาย (body detection) + จดจำใบหน้าระยะกลาง
  → ใช้ YOLOv8n.track() ติดตาม track_id ต่อเนื่อง

  攝影機 2 (Entrance Door)
  → ติดผนังซ้าย ใกล้ประตู หันเข้าห้อง
  → ทำหน้าที่: trigger เหตุการณ์ ENTER + ตรวจจับคนแปลกหน้า (UNKNOWN)
  → กล้องหลักที่สำคัญที่สุดในระบบ

  攝影機 3 (Corner Cam)
  → ติดมุมขวาบนของห้อง หันเข้าห้อง
  → ทำหน้าที่: ยืนยัน presence ของคนภายในห้อง

  攝影機 4 (Exit Door)
  → ติดข้างประตู หันเข้าห้อง
  → ทำหน้าที่: trigger เหตุการณ์ EXIT (เห็นหน้าคนที่กำลังออก)

การทำงาน:
  1. แต่ละกล้องมี background thread แยกอ่านเฟรมที่ 5fps
  2. ใช้ Motion Detection gate: ถ้า pixel เปลี่ยน < 1500 → ข้าม YOLO inference (ประหยัด CPU)
  3. YOLO ตรวจจับ bounding box ของคน (class=0)
  4. ส่ง head crop ไปยังระบบ face recognition

================================================================================
ส่วนที่ 3 — ระบบจดจำใบหน้า (Face Recognition with ArcFace)
================================================================================

ใช้ InsightFace buffalo_l model (ArcFace) ซึ่งเป็น State-of-the-art

ขั้นตอนการทำงาน:
  ① ลงทะเบียนสมาชิก: ถ่ายรูป 5 ท่า จากกล้องจริง
     (หน้าตรง / เอียงซ้าย / เอียงขวา / ก้ม / เงย)

  ② สร้าง Face Database:
     - แปลงรูปแต่ละรูปเป็น 512-dimensional embedding vector (ArcFace)
     - คำนวณ mean embedding จากทุกรูปของแต่ละคน
     - เก็บไว้ใน RAM (rebuild ทุกครั้งที่ restart)

  ③ ตรวจจับ Real-time:
     - ตัด head region จาก bounding box ของ YOLO
     - แปลงเป็น embedding ด้วย InsightFace
     - คำนวณ cosine distance กับทุก embedding ในฐานข้อมูล
     - ถ้า distance < threshold → identify สำเร็จ
     - ถ้า distance > threshold หรือ margin แคบ → UNKNOWN

  Threshold ที่ใช้:
     攝影機 2 sim_thresh = 0.45 (เข้มที่สุด)
     MIN_INTERCLASS_MARGIN = 0.15 (กัน ambiguous)

  Multi-frame Buffer:
     - เก็บ crop ใบหน้าสูงสุด 3-5 รูปต่อ track
     - ลองจำทุก crop ย้อนหลัง → เพิ่มโอกาส identify
     - Multi-frame voting: 2 ครั้งสอดคล้องกัน → force accept

ส่วนที่ 4 — ระบบควบคุมการเข้าออก (Access Control State Machine)
================================================================================

ใช้ Unified State Machine ทำงานเป็น background thread ทุก 1 วินาที

State ของแต่ละคน: {inside, entered_at, last_seen[cam], exit_pending}

─── ENTER Logic ───────────────────────────────────────────────────

  เงื่อนไขที่ trigger ENTER (ใดเงื่อนไขหนึ่ง):

  cam1 solo:   攝影機 2 เห็น + confidence ≥ 0.50
  cam2 solo:   攝影機 3 เห็น + confidence ≥ 0.55
  yolo solo:   攝影機 1 เห็น + confidence ≥ 0.65
  cross conf:  攝影機 2 + 攝影機 3 เห็นพร้อมกันใน 12 วินาที

─── EXIT Logic (2-Stage) ──────────────────────────────────────────

  Stage 1: 攝影機 4 เห็นคนเดินมาหาประตู → start exit_pending timer
  Stage 2: รอ 8 วินาที ดูกล้องอื่น (攝影機 1,2,3) ว่ายังเห็นคนไหม
           ยังเห็น → ยกเลิก EXIT (คนอยู่ในห้อง)
           ไม่เห็น → EXIT confirmed

  Grace Period: ถ้าเพิ่งเข้ามาไม่เกิน 30 วินาที → ไม่นับ EXIT
  Stale Safety: ถ้ากล้องไม่เห็นนาน 300 วินาที → auto EXIT

─── UNKNOWN Person ────────────────────────────────────────────────

  ถ้า 攝影機 2 ตรวจจับใบหน้าแต่จำไม่ได้ภายใน 8 วินาที
  → ส่งแจ้งเตือน Telegram พร้อมรูปภาพ
  → Cooldown: 5 นาทีต่อครั้ง

ส่วนที่ 5 — ระบบตรวจสอบบ่อเลี้ยงปลา (Aquaponics Sensor Monitoring)
================================================================================

ตรวจสอบ 3 บ่อ (Tank 1, 2, 3) แต่ละบ่อวัดค่า 3 ค่า:

  ┌───────────┬──────────┬──────────────────┐
  │ ค่า       │ หน่วย   │ เกณฑ์ปกติ        │
  ├───────────┼──────────┼──────────────────┤
  │ pH        │ -        │ 6.5 – 7.5        │
  │ อุณหภูมิ  │ °C       │ 22 – 27          │
  │ DO        │ mg/L     │ 6.0 – 8.0        │
  └───────────┴──────────┴──────────────────┘

ระบบ Alert (4 ระดับ):
  1. Visual เท่านั้น: ค่าใกล้ขอบเขต 15% → การ์ดเปลี่ยนสี
  2. Alert 1 (🟡): ค่าเกินเกณฑ์ติดต่อกัน ≥ 30 นาที → Telegram
  3. Alert 2 (🔴): ค่าเกินเกณฑ์ติดต่อกัน ≥ 2 ชั่วโมง → Telegram
  4. Fault (🔌): ค่าเป็น 0 นาน ≥ 2 นาที (เซ็นเซอร์เสีย) → Telegram

  + Recovery: ค่ากลับมาปกติ → แจ้งเตือน 已恢復正常

ข้อมูลถูก Sensor node เขียนลง MySQL ตาราง tank1/tank2/tank3
Frontend poll ทุก 5 วินาที แสดงกราฟ Real-time

================================================================================
ส่วนที่ 6 — Web Interface และฐานข้อมูล
================================================================================

─── หน้าเว็บ ──────────────────────────────────────────────────────

  / (Dashboard)
    - Live video stream กล้อง 4 ตัว
    - 在室人員: แสดงว่าตอนนี้มีใครอยู่ในห้อง + เวลาที่อยู่
    - ข้อมูลเซ็นเซอร์ 3 บ่อ Real-time
    - ประวัติการเข้าออกล่าสุด
    - ปุ่ม Reset state (กรณี state ค้าง)

  /personnel
    - จัดการสมาชิก (เพิ่ม/แก้ไข/ลบ)
    - อัปโหลดหรือถ่ายรูปจากกล้องจริงผ่าน 5-pose guide
    - กำหนดเวลาสิทธิ์เข้าออก (เช่น 08:00-17:00)

  /history
    - ประวัติ ENTER/EXIT ทั้งหมด
    - ค้นหาตามชื่อ/วันที่
    - ดูระยะเวลาที่อยู่ในห้อง

  /tank/1, /tank/2, /tank/3
    - กราฟประวัติค่าเซ็นเซอร์รายบ่อ

─── ฐานข้อมูล MySQL ────────────────────────────────────────────────

  ตาราง                  ข้อมูล
  ─────────────────────────────────────────────────────
  users                  บัญชีผู้ใช้ระบบ
  authorized_personnel   สมาชิก + สิทธิ์เข้าออก
  detection_logs         ประวัติการ detect (YOLO)
  room_events            ประวัติ ENTER/EXIT ทุกครั้ง
  room_occupants_log     คนที่อยู่ในห้องตอนนี้
  tank1/tank2/tank3      ข้อมูลเซ็นเซอร์แต่ละบ่อ

─── Security ───────────────────────────────────────────────────────

  - Login ด้วย username/password (Werkzeug password hash)
  - Session-based authentication (Flask session)
  - ทุก API endpoint ต้องผ่าน @login_required
  - Telegram Token เก็บใน .env (ไม่ commit ลง git)

สรุปภาพรวม Data Flow
================================================================================

กล้อง → OpenCV frame → YOLO (body detection)
                           ↓
                     InsightFace (face recognition)
                           ↓
                     State Machine (ENTER/EXIT decision)
                           ↓
                     MySQL (บันทึก event)
                           ↓
                     Web Dashboard (แสดงผล Real-time)
                           ↓ (เฉพาะกรณีพิเศษ)
                     Telegram Bot (แจ้งเตือน)

Sensor → MySQL → Web Frontend (poll 5s) → Alert Logic → Telegram
